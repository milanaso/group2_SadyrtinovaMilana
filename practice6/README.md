# Practice 6 — File Handling and Built-in Functions

## Topics
- File handling: reading, writing, appending, copying and deleting files
- File modes: `r`, `w`, `a`, `x`
- Directory management using `os` and `pathlib`
- File access and path validation
- Built-in functions: `map()`, `filter()`, `reduce()`, `enumerate()`, `zip()`
- Type checking and conversion

## Structure
- `file_handling/` — file operations and exercises
- `directory_management/` — directory creation and listing
- `builtin_functions/` — examples of Python built-in functions
