# Practice 3: Python Functions, Lambda Expressions, Classes and Inheritance

## Overview

This practice is focused on Python functions, lambda expressions, classes, objects, and inheritance.

The goal of this practice is to understand how to create reusable functions, use lambda expressions, work with classes and objects, and apply inheritance in Python.

## Learning Objectives

After completing this practice, I learned how to:

- Create and call Python functions.
- Use different types of function arguments.
- Use `*args` and `**kwargs`.
- Return values from functions.
- Create and use lambda expressions.
- Use lambda functions with `map()`, `filter()`, and `sorted()`.
- Create classes and objects.
- Use the `__init__()` constructor.
- Create and use class methods.
- Understand class variables and instance variables.
- Use inheritance between classes.
- Use the `super()` function.
- Override methods in child classes.
- Use multiple inheritance.
- Organize Python code into separate files and folders.
